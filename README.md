# Animation Explained

Interactive visual explainers for systems, algorithms, physics, and computer science.

## Cursor Animation Lab

Explore four pointer treatments: spotlight, magnetic movement, motion trail, and crosshair. The playground is available at:

- GitHub Pages: https://glitchedphoenix38.github.io/animation-explained/cursor-lab/
- Existing Vercel deployment: https://animation-explained.vercel.app

## Development

```bash
npm ci
npm run dev
```

Build a static export with `npm run build`. The GitHub Actions workflow publishes the exported site to GitHub Pages on pushes to `main`.
